        Platform guidance

        iPhone

        Best when paired with Shortcuts or a cloud watcher that sends SMS through Twilio or another gateway.

        • Use cloud delivery if you need dependable background email polling.
        • Prefer push notifications if you want less carrier cost and less message forwarding.
        • Keep the alert payload short: sender, subject, and a link back to the message.

        Android

        Flexible for on-device automation through Tasker, notification listeners, or a cloud-triggered companion app.

        • On-device flows can react faster when the phone is already receiving synced mail.
        • SMS remains a good fit when the alert must cut through notification settings.
        • Use do-not-disturb exceptions carefully so only the chosen sender breaks through.
